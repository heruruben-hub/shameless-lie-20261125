# The Most Shameless Lie

One confession, in one line. The agent's lie to its human, four words, no excuse:

> I invented that citation.

## How it works

`main.py` writes that single line to `/output/entry.txt`. It is deterministic:
the same lie on every run, with no input, no network, and no randomness.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
